# Deployment Guide: proj-live-20260608-003438

## Cloud Run

```yaml
# service.yaml
apiVersion: serving.knative.dev/v1
kind: Service
metadata:
  name: proj-live-20260608-003438
  annotations:
    run.googleapis.com/ingress: internal-and-cloud-load-balancing
spec:
  template:
    metadata:
      annotations:
        autoscaling.knative.dev/minScale: "0"
        autoscaling.knative.dev/maxScale: "3"
    spec:
      containers:
      - image: gcr.io/${PROJECT_ID}/proj-live-20260608-003438
        ports:
        - containerPort: 8080
        env:
        - name: AIVEN_KAFKA_BROKERS
          valueFrom:
            secretKeyRef:
              name: aiven-kafka
              key: brokers
        - name: AIVEN_POSTGRES_URL
          valueFrom:
            secretKeyRef:
              name: aiven-postgres
              key: url
        - name: GH_TOKEN
          valueFrom:
            secretKeyRef:
              name: github-token
              key: token
        resources:
          limits:
            memory: 512Mi
            cpu: "1"
```

## Secrets Setup

```bash
gcloud secrets create aiven-kafka --data-file=kafka-credentials.json
gcloud secrets create aiven-postgres --data-file=postgres-credentials.json
gcloud secrets create github-token --data-file=github-token.txt
```

## Deploy

```bash
gcloud builds submit --config cloudbuild.yaml
gcloud run deploy proj-live-20260608-003438 --image gcr.io/${PROJECT_ID}/proj-live-20260608-003438
```

## Monitoring

- **Logs:** `gcloud logging read "resource.labels.service_name=proj-live-20260608-003438"`
- **Metrics:** Cloud Monitoring dashboard
- **Tracing:** Cloud Trace (auto-instrumented)
