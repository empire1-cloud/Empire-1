# Empire Revenue OS — Demo Checklist

## Pre-Demo Setup

- [ ] Start local backend: `uv run backend/app/main.py` (or via systemd)
- [ ] Verify backend health: `curl http://localhost:8000/api/revenue-receipts/health`
- [ ] Start frontend: `npm run dev` (or `npx next dev`)
- [ ] Open browser to `http://localhost:3000/revenue-os`
- [ ] Load sample payload file: `backend/app/data/revenue_os/sample_payloads.json`
- [ ] Confirm the command panel placeholder shows "Run Empire Revenue OS Command"

## Demo Walkthrough

### 1. Command Panel — Run Empire-1 Demo Payload
- [ ] Click "Run Empire Revenue OS Command"
- [ ] Wait for full output to render
- [ ] **Verify receipt ID** and **command ID** are displayed
- [ ] **Verify 3 forged offers** shown with price tiers (low / med / high)
- [ ] **Verify ~25 buyer profiles** shown in the buyer list section
- [ ] **Verify cold DMs / emails / follow-ups** section is populated
- [ ] Confirm gold markers (`✅`) on each revenue step
- [ ] Confirm `$` price breakdown includes payment capture amounts
- [ ] Confirm buyer persona segment is visible

### 2. Pipeline Composer
- [ ] Verify leads appear after command run
- [ ] **Create a new lead** with name, segment, and estimated value
- [ ] **Change lead status** through the pipeline (new → targeted → contacted → replied → call_booked → invoice_sent → paid)
- [ ] Verify paid leads show actual value in the pipeline

### 3. Checkout Desk — Manual Payment Fallback
- [ ] Click "Create Checkout"
- [ ] Verify **offer name** and **recommended price** are shown
- [ ] Verify `Stripe Configured: No — manual payment` is displayed
- [ ] **Verify manual payment instruction box** is visible (yellow box with 4 steps)
- [ ] Confirm the workflow is NOT blocked by missing Stripe

### 4. Delivery Receipt — Copy & Export
- [ ] Click "Generate Delivery Receipt"
- [ ] Verify **receipt ID**, **customer name**, and **purchased offer** are shown
- [ ] Expand "Delivered Assets" accordion to verify asset list
- [ ] **Click "Copy"** button — confirm clipboard write succeeded
- [ ] **Click "Download"** button — confirm `.txt` file downloads

### 5. Analytics Panel
- [ ] Verify data loads automatically on mount
- [ ] Check for displayed metrics: total receipts, checks run, offers forged, pipeline count

### 6. Dashboard CTA
- [ ] Navigate to `/dashboard`
- [ ] Verify the Revenue OS CTA card shows the core promise copy
- [ ] Click "Launch Revenue OS" — confirm it routes to `/revenue-os`

## Recording

- [ ] **Record 90-second demo walkthrough** hitting all steps above
- [ ] Upload to Loom / QuickTime / OBS for sharing

## Paid Outreach (Post-Demo)

- [ ] Pick a sample payload from `sample_payloads.json` (Empire-1, Agency, or Creator brand)
- [ ] Run the command for that payload
- [ ] Note the buyer list generated by the AI
- [ ] **Send first 50 outreach messages** (DMs, emails, or posts)
- [ ] Track responses in Pipeline Composer
- [ ] Send invoice (manual or Stripe)
- [ ] Mark lead as paid
- [ ] Generate and copy delivery receipt
- [ ] Send receipt to buyer
- [ ] Log revenue in Analytics

## Post-Demo Cleanup

- [ ] Reset pipeline data if needed (clear localStorage)
- [ ] Check backend logs for errors
- [ ] Confirm no uncommitted changes unrelated to Revenue OS
